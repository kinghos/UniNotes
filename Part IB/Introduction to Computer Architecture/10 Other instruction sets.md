#### x86
- CISC design
	- Variable length instructions, highly complex to decode
	- Many registers are special purpose
	- Instructions are decoded into micro-operations that are similar to RISC instructions
#### ARM
- All instructions are conditional
- Load and store multiple instructions
- Richer addressing modes

#### Java bytecode
- Focused on portabliity
- Intermediate representation, that is interpreted or compiled to native code
- Stack-based machine
	- Operand stack instead of registers
- Variable length instruction set
