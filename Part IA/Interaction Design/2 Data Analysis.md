Converting qualitative data to quantitative data means there is loss of depth

#### Quantitative analysis
- Measure of central tendency
	- Mean
	- Median
	- Mode
- Measure of variability
	- Range
	- Standard deviation
	- Variance
- Measure of categorical distribution
	- Percentages
Anscombe quartet - regression is not always the best metric, vastly different datasets can give the same line

#### Qualitative analysis
- Looking for critical incidents
- Identifying themes
	- Inductive analysis
- Categorising data
	- Categorisation scheme pre-configured
	- Deductive analysis
Present as an evidence chain - how the derived findings arise from the underlying data
