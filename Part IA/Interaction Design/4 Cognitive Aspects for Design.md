#### Memory
Short term memory is limited in duration, and limited in capacity
Long-term memory has explicit (declarative memory) which is responsible for events, experiences, facts and concepts
Implicit (procedural memory) is motor skills
Practice improves memory, so does surprise

#### Gestalt principles
We tend to group similar elements into one perceptual unit
Close in space, same shape, colour, enclosed by a border
Foreground, background, filling in the gaps
