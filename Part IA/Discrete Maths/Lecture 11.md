#### Boolean algebra
Union and intersection are associative, commutative and idempotent
The empty set is a neutral element for $\cup$ and the universal set is a neutral element for $\cap$. Vice versa, it is the annihilator.
With respect to each other, they are distributive and absorptive

#### Pairing axiom
For every a and b, there is a set with a and b as its only elements.
The set $\{ a,a \}$ is abbreviated as $\{ a \}$ and referred to as a singleton
