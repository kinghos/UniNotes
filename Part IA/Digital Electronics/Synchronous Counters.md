An excitation table is a table that says the required FF input value required to achieve a particular state from a given current state.
![[ExcitationTable.png]]
If using [[J-K Flip-Flop|J-K FFs]], J and K columns are needed for each FF
For [[Flip-Flops|D types]], the FF inputs are the same as the next state
Combinational logic must be determined to give the correct FF inputs (from the current outputs)
Unused counts can be used as don't care states
