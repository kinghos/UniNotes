Software process - a structured set of activities required to develop a software system
Consists of specification, design and implementation, validation and evolution
#### Waterfall model
Stages of:
- Requirements
- System and software design
- Implementation and unit testing
- Integration and system testing
- Operation and maintenance
If changes are made to the milestones, then the whole thing needs to be redone. Waterfall assumes requirements are frozen

#### Spiral model
Iterative version of waterfall
