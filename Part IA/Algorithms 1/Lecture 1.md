#### Features of algorithms
An algorithm is any well-defined computational procedure that takes some value, or set of values, as input and produces some value, or set as values, as output.
##### Problems and problem instances
Problems have a specified input and output. These need to be precise
A problem instance is a specific set of inputs.
Think of it as problems are general e.g. can be written algebraically while problem instances are specific examples e.g. actual numeric input data.
##### Correctness
We say that an algorithm is correct if, for every input instance, the algorithm terminates with the correct output. An incorrect algorithm might not halt or could give a wrong answer.
