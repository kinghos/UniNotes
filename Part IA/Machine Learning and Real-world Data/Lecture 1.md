Sentiment classification - the task of automatically deciding whether a review is positive or negative based on the text of the review
For a very simple form of sentiment analysis, you can tally the number of positive words vs negative words and see which is greater.

Accuracy can be calculated using a metric like star ratings which can help see if the sentiment analysis was correct.
