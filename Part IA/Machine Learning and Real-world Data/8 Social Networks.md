Reasons for investigating social networks:
- Academic investigation of human behaviour
- Identifying well-connected individuals and links between subcommunities
- Modelling information flow
	- Targeted advertising
	- Novelty/origin
- Lots of applications in conjunction with other approaches: e.g. sentiment analysis of tweets plus network analysis
- Disease transmission in epidemics

Networks are modelled as undirected, unweighted graphs.
- Distance is the length of shortest path between two nodes
- Diameter of a graph is the maximum distance between any pair of nodes
- The degree of a node is the number of neighbours a node has in the graph  
#### Small world phenomenon
A small world network is one in which
- Overall there aren't many connections
- There are closely clustered regions
- These are connected by only a few links
Low average path length: Most nodes can be reached from each other by a small number of hops
- High clustering coefficient - nodes tend to form tightly knit groups (a nodes neighbours are likely to be neighbours of each other)
- Small average path length - steps between nodes tend to grow logarithmically with network size
- Spare connectivity  - The overall network has relatively few edges compared to a complete graph yet maintains high
